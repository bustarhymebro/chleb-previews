# chleb-previews

Static-HTML hosting for Chleb AI's daily Website Preview Builder cron.

Each subdirectory `<slug>/index.html` is a 1-page custom website preview generated by the cron at 05:00 ET, pushed here, and served at `https://previews.chleb.ai/<slug>/` via GitHub Pages.

The Preview HTML template lives in `dashboard/src/lib/preview-template.ts` in the main Chleb dashboard repo. Edits to the template propagate to all future previews on the next cron run.

Manual edits to existing previews here will be overwritten if the cron regenerates them.
