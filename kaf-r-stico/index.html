About

How we run the truck in Riverview

We started Kafé Rústico because Riverview has plenty of chain options and not enough food that tastes like somebody's abuela actually made it. We cook everything from scratch on the truck, run a tight menu so the line moves, and post our location early so regulars know where to find us. If you've eaten with us once, you already know the cafecito is the move.
