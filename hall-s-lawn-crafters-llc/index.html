The plan list

How we run yards in Tampa

  • Weekly mow + edge package
    Mow, line trim, hard edge on walks and drive, blow off all surfaces. Standard 52-week schedule, billed monthly.
  • Bi-weekly winter rotation
    Reduced cadence November through February when St. Augustine slows down. Same crew, every other week, adjusted rate.
  • One-time yard reset
    For overgrown or vacant properties. Heavy cut, beds cleared, debris hauled. Quoted on site before we start.
  • Hedge shaping visit
    Quarterly trim on hedges and ornamentals. Sharp lines, no scalping, clippings bagged and taken with us.
  • Mulch refresh
    Pine bark or cypress, two-inch top-off in existing beds. Edges cleaned before laydown so the bed lines stay defined.
